# FIFA-19-Player-Dataset---Exploratory-Data-Analysis-EDA-
Exploratory Data Analysis (EDA) of the FIFA 19 Player Dataset using Python, Pandas, NumPy, Matplotlib, and Seaborn. Analyzed 17,918 player records to uncover insights on age, ratings, market value, wages, positions, and player performance through data cleaning, feature engineering, statistical analysis, and visualizations.
